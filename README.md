# Geely EX2 Charge Control — APK Releases

Public binary releases for the unofficial Geely EX2 Charge Control project.

Download the head-unit agent and Android phone controller from the [Releases](../../releases) page. Verify downloaded files against the attached `SHA256SUMS` before installation.

## Packages

- `com.ex2cc.agent` — Flyme Auto head-unit agent (Android API 28 or newer)
- `com.ex2cc.controller` — Android phone controller

The applications communicate over the local network. Pairing uses a one-time code, certificate pinning, and per-car credentials. Vehicle controls remain subject to on-car capability checks and supervised commissioning.

## Important

- Unofficial software; not affiliated with Geely, Meizu, Flyme, or ECARX.
- Preview builds are debug-signed and require supervised testing while parked.
- Keep the stock charging interface available and independently verify charging behavior.
- APK files can inherently be inspected or decompiled; binary distribution cannot prevent reverse engineering.
- Provided without warranty. Use at your own risk.

Application source code is maintained in a separate private repository and is not published here.
